# Test Cases: ResetPasswordComponent

| ID del Test | Tipo | Escenario / Propósito | Precondiciones | Pasos clave | Resultado Esperado | Justificación de Valor |
|---|---|---|---|---|---|---|
| TC-ResetPasswordHappyPath | E2E | Restablecer contraseña con token válido muestra el mensaje de éxito y el botón de login | URL contiene `?token=valid-token`; `authService.confirmPasswordReset` retorna éxito | 1. Navegar a la ruta con token en query param. 2. Introducir contraseña y confirmación iguales y válidas. 3. Enviar el formulario. | El bloque de éxito es visible; el formulario desaparece; aparece el botón "Go to sign in" | Es el flujo final del proceso de recuperación de contraseña; su fallo deja al usuario bloqueado |
| TC-ResetPasswordNoToken | Componente | Acceder sin token en la URL muestra el estado de token inválido | URL sin query param `token` | 1. Inicializar el componente sin `?token=`. 2. Verificar `ngOnInit`. | `isInvalidToken()` es `true`; el formulario no está en el DOM; aparece el botón "Request a new link" | Valida el edge case crítico de un enlace caducado o manipulado |
| TC-ResetPasswordPasswordMismatch | Componente | Contraseñas que no coinciden bloquean el envío | Componente renderizado con token válido en URL | 1. Introducir contraseñas distintas en `password` y `confirm`. 2. Intentar enviar. | El formulario es inválido por `passwordMismatch`; `authService.confirmPasswordReset` no es invocado | El validador cruzado es lógica custom; este test protege la integridad del dato enviado al backend |
| TC-ResetPasswordApiError | Integración | Un error de API (ej. token expirado en servidor) muestra el mensaje de error | Token presente en URL; `authService.confirmPasswordReset` retorna `throwError(() => new Error('Token expired'))` | 1. Enviar formulario con contraseñas válidas. 2. El servicio rechaza la petición. | El bloque de error muestra `'Token expired'`; `status` es `'error'` | Garantiza que errores de servidor (token expirado, ya usado) son comunicados al usuario |
| TC-ResetPasswordLoadingState | Componente | El botón queda deshabilitado durante el envío | Token presente; `authService.confirmPasswordReset` retorna un Observable que no completa | 1. Enviar formulario válido. 2. Verificar estado antes de que complete. | `isLoading()` es `true`; el botón está `disabled`; un segundo `onSubmit()` es ignorado | Protege contra envíos dobles que podrían causar estados inconsistentes |
| TC-ResetPasswordGoToForgotPassword | Componente | El botón "Request a new link" navega a la página de forgot-password | `isInvalidToken()` es `true` | 1. Hacer clic en el botón "Request a new link" (o llamar `goToForgotPassword()`). | `router.navigate` es llamado con `['/auth/forgot-password']` | Valida la navegación del flujo de recuperación cuando el token es inválido |
