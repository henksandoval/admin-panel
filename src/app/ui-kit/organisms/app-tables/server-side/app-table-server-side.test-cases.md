# Test Cases — AppTableServerSideComponent

| ID del Test | Tipo | Escenario / Propósito | Precondiciones | Pasos clave | Resultado Esperado | Justificación de Valor |
|---|---|---|---|---|---|---|
| TC-CurrentParams | Componente | `currentParams` refleja los filtros, sort, pageIndex y pageSize actuales | Estado con filtros y sort configurados | 1. Configurar estado inicial con filtros, sort y paginación. 2. Leer `currentParams()`. | El objeto contiene los valores actuales de todos los parámetros. | Garantiza que el payload enviado al backend es consistente con el estado de la UI. |
| TC-FiltersChangeResetsPage | Componente | `onFiltersChange` convierte criterios a valores, resetea `pageIndex` y emite ambos outputs | `pageIndex = 3`, `resetPageOnFilter = true` | 1. Llamar `onFiltersChange(criteria)`. | `pageIndex` queda en 0. `filtersChange` y `paramsChange` emiten con los datos correctos. | Garantiza sincronización completa del estado con el backend al filtrar. |
| TC-FiltersChangeNoReset | Componente | `onFiltersChange` no resetea `pageIndex` cuando `resetPageOnFilter` es `false` | `pageIndex = 3`, `resetPageOnFilter = false` | 1. Llamar `onFiltersChange(criteria)`. | `pageIndex` se mantiene en 3. | Permite búsqueda en vivo sin perder la posición de página. |
| TC-SortChangeEmit | Componente | `onSortChange` actualiza el sort y emite `paramsChange` | — | 1. Llamar `onSortChange({ active: 'name', direction: 'asc' })`. | `paramsChange` emite con el sort actualizado. | Garantiza que el cambio de orden de columna llega al backend correctamente. |
| TC-PageChangeEmit | Componente | `onPageChange` emite `paramsChange` con `pageIndex` y `pageSize` actualizados | — | 1. Llamar `onPageChange({ pageIndex: 2, pageSize: 20 })`. | `paramsChange` emite con los nuevos valores de paginación. | Garantiza que la navegación de página llega al backend correctamente. |
| TC-SkipBoundaryGuardEmpty | Componente | `skipBoundaryGuard` retorna `true` cuando `totalItems` es 0 | `totalItems = 0` | 1. Setear `totalItems = 0`. 2. Leer `skipBoundaryGuard()`. | Retorna `true`. | Evita el reseteo prematuro de página cuando la primera carga aún no ha retornado datos. |
| TC-SkipBoundaryGuardWithData | Componente | `skipBoundaryGuard` retorna `false` cuando `totalItems` es mayor a 0 | `totalItems = 50` | 1. Setear `totalItems = 50`. 2. Leer `skipBoundaryGuard()`. | Retorna `false`. | Permite el reseteo de página cuando ya hay datos cargados y el total es conocido. |
