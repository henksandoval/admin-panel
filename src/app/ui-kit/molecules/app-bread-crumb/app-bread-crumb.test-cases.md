# Test Cases — AppBreadCrumbComponent

| ID del Test | Tipo | Escenario / Propósito | Precondiciones | Pasos clave | Resultado Esperado | Justificación de Valor |
|---|---|---|---|---|---|---|
| TC-RendersBreadcrumbItems | Componente | Renderiza un pill por cada item recibido en `items` | `items` con 3 breadcrumbs | 1. Renderizar el componente con 3 items. 2. Detectar cambios. | Existen 3 elementos `.app-bread-crumb-pill` en el DOM. | Garantiza que todos los niveles de navegación se muestran correctamente. |
| TC-NavigableItemHasRouterLink | Componente | El pill de un item con `route` tiene `routerLink` y no la clase `no-route` | Breadcrumb con `route` definido | 1. Proveer item con `route = '/usuarios'`. 2. Detectar cambios. | El elemento `<a>` tiene el atributo `routerLink` y no tiene la clase `no-route`. | Garantiza que los niveles intermedios de navegación son clicables. |
| TC-LastItemNoRoute | Componente | El último item (página actual) tiene la clase `no-route` independientemente de si tiene `route` | Último breadcrumb con o sin `route` | 1. Proveer items donde el último tiene `route`. 2. Detectar cambios. | El último `<a>` tiene la clase `no-route`. | El último breadcrumb representa la página actual y no debe ser un enlace navegable. |
| TC-SeparatorBetweenItems | Componente | Renderiza separadores `chevron_right` entre los items, pero no después del último | 3 breadcrumb items | 1. Proveer 3 items. 2. Detectar cambios. | Existen exactamente 2 iconos separadores `chevron_right`. | Garantiza la correcta presentación visual de la jerarquía de navegación. |
| TC-EmptyBreadcrumbs | Componente | No renderiza ningún pill cuando `items` está vacío | `items = []` | 1. Renderizar con `items = []`. 2. Detectar cambios. | No existen elementos `.app-bread-crumb-pill` en el DOM. | Edge case: la ruta raíz o páginas sin jerarquía no deben romper el componente. |
