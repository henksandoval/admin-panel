# Test Cases — AppFormSelectComponent

| ID del Test | Tipo | Escenario / Propósito | Precondiciones | Pasos clave | Resultado Esperado | Justificación de Valor |
|---|---|---|---|---|---|---|
| TC-InitialValue | Componente | Renderiza el valor inicial del `FormControl` seleccionado en el select | — | 1. Crear `FormControl('valor-1')`. 2. Proveer opciones. 3. Detectar cambios. | La opción `'valor-1'` aparece seleccionada. | Garantiza la hidratación inicial desde el modelo de datos. |
| TC-FormControlSync | Componente | Actualiza el `FormControl` cuando se selecciona una opción | — | 1. Crear `FormControl(null)`. 2. Simular selección de opción. | `control.value` es la opción seleccionada. | Happy path crítico: sin esto el select no registra la selección. |
| TC-ErrorDisplayTouched | Componente | Muestra el error cuando el control es inválido y ha sido tocado | `Validators.required` | 1. Marcar el control como tocado. 2. Detectar cambios. | Existe `mat-error` con el mensaje de error. | Garantiza el feedback de validación en el flujo estándar. |
| TC-ErrorHiddenUntouched | Componente | No muestra error cuando el control es inválido pero no tocado | `Validators.required` | 1. No tocar el control. 2. Detectar cambios. | No existe `mat-error`. | Evita errores prematuros antes de la interacción. |
| TC-CustomErrorMessage | Componente | `config.errorMessages` sobreescribe el mensaje de error por defecto | Control tocado e inválido | 1. Setear `config.errorMessages` con mensaje custom. 2. Detectar cambios. | `mat-error` muestra el mensaje personalizado. | Permite mensajes contextuales por campo. |
| TC-DisabledState | Componente | Deshabilita el select cuando el `FormControl` está deshabilitado | — | 1. Crear `FormControl({ value: null, disabled: true })`. 2. Detectar cambios. | El `mat-select` está deshabilitado. | Previene selección en campos de solo lectura. |
| TC-IsRequired | Componente | `isRequired()` es `true` cuando se usa `Validators.required` | — | 1. Crear `FormControl(null, Validators.required)`. | `component.isRequired() === true`. | Garantiza la semántica correcta de campo obligatorio. |
| TC-RendersAllOptions | Componente | Renderiza todas las opciones provistas | 3 opciones en el array | 1. Proveer 3 opciones. 2. Detectar cambios. | Existen 3 elementos `mat-option` en el DOM. | Garantiza que todas las opciones de negocio estén disponibles. |
| TC-GroupedOptions | Componente | Renderiza opciones agrupadas cuando tienen la propiedad `group` | Opciones con `group` definido | 1. Proveer opciones con grupos. 2. | TC-MultipleSelection | Componente | Soporta selección múltiple cuando `config.multiple = true` | — | 1. Setear `config.multiple = true`. 2. | TC-IndividualOptionDisabled | Componente | Deshabilita opciones individuales marcadas como `disabled` | Opción con `disabled: true` | 1. Proveer opciones con una marcada como `disabled`. 2. Detectar cambios. | Solo esa opción está deshabilitada. | Permite excluir opciones no válidas para el estado actual sin eliminarlas. |
| TC-DensityClass | Componente | Aplica la clase de densidad al elemento host | `config.density = -2` | 1. Setear densidad. 2. Verificar el host element. | El host tiene la clase de densidad correspondiente. | Garantiza el ajuste de tamaño del select en formularios compactos. |
