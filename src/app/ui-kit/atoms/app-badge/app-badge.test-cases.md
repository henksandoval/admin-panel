# Test Cases — AppBadgeComponent

| ID del Test | Tipo | Escenario / Propósito | Precondiciones | Pasos clave | Resultado Esperado | Justificación de Valor |
|---|---|---|---|---|---|---|
| TC-DefaultValues | Componente | Crea el componente con todos los valores por defecto | — | 1. Instanciar el componente sin inputs. 2. Detectar cambios. | El componente existe con los defaults definidos en `BADGE_DEFAULTS`. | Verifica el contrato de la API pública del componente. |
| TC-InlineColorClass | Componente | `inlineClasses` incluye siempre la clase de color actual | — | 1. Renderizar con `color = 'accent'`. 2. Leer `inlineClasses()`. | El resultado contiene `app-badge` y el color configurado. | Garantiza que el color nunca quede sin aplicar en modo inline. |
| TC-InlineIndicator | Componente | `inlineClasses` añade `has-indicator` solo cuando `hasIndicator` es `true` | — | 1. Renderizar con `hasIndicator = true`. 2. Repetir con `false`. | Solo con `true` la clase `has-indicator` está presente. | Previene que el indicador visual aparezca cuando no debe. |
| TC-InlineSizeClass | Componente | `inlineClasses` añade `badge-size-*` solo cuando el tamaño difiere del default | — | 1. Renderizar con tamaño `small`. 2. Repetir con el tamaño default. | Solo el tamaño custom genera la clase `badge-size-small`. | Evita clases CSS innecesarias cuando el default ya maneja el estilo. |
| TC-OverlayMaterialColor | Componente | `overlayColor` devuelve el color cuando es un color válido de Material | — | 1. Setear `color = 'accent'`. 2. Leer `overlayColor()`. | Retorna `'accent'`. | Garantiza la interoperabilidad con los atributos de Material (`matBadgeColor`). |
| TC-OverlayFallbackColor | Componente | `overlayColor` cae en `primary` para colores que no son de Material | — | 1. Setear `color = 'success'`. 2. Leer `overlayColor()`. | Retorna `'primary'`. | Evita que `matBadgeColor` reciba un valor inválido que rompa la UI. |
| TC-MatBadgeSizeDefault | Componente | `matBadgeSize` retorna `medium` cuando el tamaño es el default | — | 1. No configurar `size`. 2. Leer `matBadgeSize()`. | Retorna `'medium'`. | Asegura que el tamaño del overlay de Material no se sobreescriba innecesariamente. |
| TC-MatBadgeSizeCustom | Componente | `matBadgeSize` retorna el tamaño real cuando difiere del default | — | 1. Setear `size = 'small'`. 2. Leer `matBadgeSize()`. | Retorna `'small'`. | Asegura que los tamaños custom se apliquen correctamente al badge de Material. |
| TC-InlineVariantRender | Componente | Renderiza un `<span>` en la variante `inline` | — | 1. Configurar `variant = 'inline'`. 2. Consultar el DOM. | Existe un elemento `<span>` en el template. No existe un div con `matBadge`. | Verifica la bifurcación de renderizado entre los dos modos del badge. |
| TC-OverlayVariantRender | Componente | Renderiza un `<div>` con `matBadge` en la variante `overlay` | — | 1. Configurar `variant = 'overlay'`. 2. Consultar el DOM. | Existe un `div` con el atributo `matBadge`. | Garantiza el modo overlay que posiciona el badge encima del contenido. |
| TC-AriaLabel | Componente | Aplica el `aria-label` cuando se provee | — | 1. Setear `ariaLabel = 'Nuevos mensajes'`. 2. Detectar cambios. | El elemento host tiene el atributo `aria-label` con el valor correcto. | Garantiza accesibilidad, requerida por los estándares WCAG. |
