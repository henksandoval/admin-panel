# Test Cases — AppPaginationComponent

| ID del Test | Tipo | Escenario / Propósito | Precondiciones | Pasos clave | Resultado Esperado | Justificación de Valor |
|---|---|---|---|---|---|---|
| TC-RangeLabelEmpty | Componente | `rangeLabel` retorna `'0 de 0'` cuando `totalItems` es 0 | — | 1. Configurar `state` con `totalItems = 0`. 2. Leer `rangeLabel()`. | Retorna `'0 de 0'`. | Edge case crítico: evita mostrar rangos incorrectos cuando no hay datos. |
| TC-RangeLabelMiddlePage | Componente | `rangeLabel` calcula correctamente el rango para una página intermedia | `totalItems = 100`, `pageSize = 10` | 1. Configurar `pageIndex = 2`. 2. Leer `rangeLabel()`. | Retorna el rango correcto (ej. `'21 - 30 de 100'`). | Garantiza que la información de paginación visible sea precisa. |
| TC-RangeLabelLastPage | Componente | `rangeLabel` recorta el índice final a `totalItems` en la última página | `totalItems = 95`, `pageSize = 10` | 1. Configurar `pageIndex = 9`. 2. Leer `rangeLabel()`. | El índice final es `95`, no `100`. | Evita mostrar rangos superiores al total real de ítems. |
| TC-IsFirstPage | Componente | `isFirstPage` es `true` cuando `pageIndex` es 0 | — | 1. Setear `pageIndex = 0`. 2. Leer `isFirstPage()`. | Retorna `true`. | Necesario para deshabilitar el botón "Anterior" en la primera página. |
| TC-IsLastPage | Componente | `isLastPage` es `true` cuando `pageIndex` es la última página | `totalItems = 30`, `pageSize = 10` | 1. Setear `pageIndex = 2`. 2. Leer `isLastPage()`. | Retorna `true`. | Necesario para deshabilitar el botón "Siguiente" en la última página. |
| TC-NavigationNextEmit | Componente | `goToNextPage` emite el evento correcto | `pageIndex = 0`, `totalItems > 0` | 1. Suscribirse a `pageChange`. 2. Llamar `goToNextPage()`. | Emite `pageChange` con `pageIndex = 1`. | Happy path crítico de navegación entre páginas. |
| TC-NavigationPrevEmit | Componente | `goToPreviousPage` emite el evento correcto | `pageIndex = 2` | 1. Suscribirse a `pageChange`. 2. Llamar `goToPreviousPage()`. | Emite `pageChange` con `pageIndex = 1`. | Happy path crítico de navegación hacia atrás. |
| TC-NavigationBoundaryFirst | Componente | No emite cuando ya está en la primera página y se intenta ir atrás | `pageIndex = 0` | 1. Llamar `goToPreviousPage()`. | El output `pageChange` no emite. | Evita solicitudes innecesarias o estados de página inválidos. |
| TC-NavigationBoundaryLast | Componente | No emite cuando ya está en la última página y se intenta avanzar | `pageIndex = última página` | 1. Llamar `goToNextPage()`. | El output `pageChange` no emite. | Evita solicitudes innecesarias o estados de página inválidos. |
| TC-PageSizeChange | Componente | `onPageSizeChange` recalcula `pageIndex` para mantener el primer ítem visible | `pageIndex = 2`, `pageSize = 10`, cambia a `pageSize = 20` | 1. Llamar `onPageSizeChange(20)`. 2. Leer el pageIndex emitido. | El `pageIndex` emitido se ajusta para que el primer ítem de la página anterior siga siendo visible. | Edge case de UX: el usuario no debe perder su posición al cambiar el tamaño de página. |
