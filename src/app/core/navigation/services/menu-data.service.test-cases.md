|--------------------------------|-------------|---------------------------------------------------------------------------------|------------------------------------------------------------------|----------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------|
| TC-LoadMenu-Success            | Integración | Carga el menú desde la API y actualiza las señales con los ítems transformados  | `ROUTE_REGISTRY` tiene entradas para todos los IDs del JSON      | 1. | TC-LoadMenu-UnknownId-Filtered | Integración | Ítems cuyo ID no existe en `ROUTE_REGISTRY` son ignorados y se emite un warning | `ROUTE_REGISTRY` no tiene entrada para el ID `'unknown-feature'` | 1. | TC-LoadMenu-ApiError           | Integración | Error HTTP limpia las señales y relanza la excepción                            | API responde con error 500                                       | 1. El error es relanzado para que `InitializationService` lo maneje.                             | Asegura un estado limpio y predecible ante fallos de red; evita que datos parciales o inválidos contaminen la navegación. |
