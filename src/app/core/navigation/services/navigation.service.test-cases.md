# Test Cases: NavigationService

| ID del Test                | Tipo        | Escenario / Propósito                                                              | Precondiciones                                                                 | Pasos clave                                                                         | Resultado Esperado                                                                                  | Justificación de Valor                                                                                                |
|----------------------------|-------------|------------------------------------------------------------------------------------|--------------------------------------------------------------------------------|-------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------|
| TC-Breadcrumbs-DirectMatch | Integración | Genera breadcrumbs correctos para una URL que coincide con un ítem de primer nivel | `navigationItems` cargados, URL actual = `/dashboard`                          | 1. Router emite `NavigationEnd` con `/dashboard`. 2. Leer signal `breadcrumbs`.     | `breadcrumbs` contiene un ítem con `label` y `route` del ítem de navegación correspondiente.        | Valida el caso base del breadcrumb; una ruta de nivel superior sin ancestros debe mostrar solo su propio ítem.        |
| TC-Breadcrumbs-NestedRoute | Integración | Genera la cadena completa de breadcrumbs para rutas anidadas                       | Árbol de navegación con padre `Apps` e hijo `Products`, URL = `/apps/products` | 1. Router emite `NavigationEnd` con `/apps/products`. 2. Leer signal `breadcrumbs`. | `breadcrumbs` = `[{ label: 'Apps', route: null }, { label: 'Products', route: '/apps/products' }]`. | Cubre la ruta más común del usuario; sin la cadena completa, el usuario pierde el contexto de dónde está en la app.   |
| TC-Breadcrumbs-UnknownUrl  | Integración | Retorna breadcrumbs vacíos para URLs que no existen en el menú de navegación       | `navigationItems` cargados, URL = `/ruta-inexistente`                          | 1. Router emite `NavigationEnd` con `/ruta-inexistente`.                            | `breadcrumbs` = `[]`.                                                                               | Garantiza que páginas de error o rutas de autenticación no muestren breadcrumbs incorrectos o de sesiones anteriores. |
| TC-UpdateActiveRootItem    | Integración | Identifica el ítem raíz activo basado en la URL actual y sus hijos                 | URL actual corresponde a una ruta hija del ítem raíz `Apps`                    | 1. Llamar `updateActiveRootItem()` con URL activa bajo `Apps`.                      | `activeRootItemId` signal = `'apps'`.                                                               | Necesario para que el menú lateral resalte el ítem padre correcto cuando el usuario está en una ruta hija.            |
