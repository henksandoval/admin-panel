# Test Cases: SettingsService

| ID del Test | Tipo | Escenario / Propósito | Precondiciones | Pasos clave | Resultado Esperado | Justificación de Valor |
|---|---|---|---|---|---|---|
| TC-LoadFromLocalStorage | Integración | La configuración guardada en localStorage se restaura al instanciar el servicio | `localStorage` tiene `'app-settings'` = `{ theme: 'deep-ocean', scheme: 'dark' }` | 1. Instanciar `SettingsService`. 2. Leer `config` signal. | `config()` = `{ theme: 'deep-ocean', scheme: 'dark' }`. | Garantiza que la preferencia de tema del usuario persiste entre sesiones; sin esto, el tema se reinicia en cada visita. |
| TC-CorruptedStorage-Fallback | Integración | JSON inválido en localStorage usa los valores por defecto sin lanzar error | `localStorage` tiene `'app-settings'` = `'{ invalid json'` | 1. Instanciar `SettingsService`. 2. Leer `config` signal. | `config()` = `{ theme: 'default', scheme: 'light' }`. La app no falla. | Previene errores de inicialización causados por datos corruptos en localStorage (limpieza del navegador, inyección manual). |
| TC-SetTheme-AppliesClass | Integración | Cambiar el tema aplica la clase CSS correcta al `body` y elimina la anterior | Servicio instanciado con tema `'default'` | 1. Llamar `setTheme('aurora-tech')`. | `document.body` tiene la clase `'theme-aurora-tech'` y ya no tiene `'theme-default'`. | Verifica el efecto secundario crítico del servicio; si las clases anteriores no se eliminan, los temas se acumulan y el CSS se corrompe. |
| TC-SetScheme-Auto-DarkOS | Integración | Esquema `'auto'` aplica tema oscuro cuando el sistema operativo está en modo oscuro | `window.matchMedia('(prefers-color-scheme: dark)')` retorna `true` | 1. Llamar `setScheme('auto')`. | `document.body` tiene la clase `'dark-theme'`. `isDarkMode` retorna `true`. | El modo auto es la preferencia más usada por usuarios modernos; un error aquí afecta a la mayoría. |
| TC-Settings-SavedOnChange | Integración | Cualquier cambio de tema o esquema persiste automáticamente en localStorage | `SettingsService` instanciado | 1. Llamar `setTheme('forest-growth')`. 2. Leer `localStorage.getItem('app-settings')`. | `localStorage` contiene `{ theme: 'forest-growth', scheme: ... }` actualizado. | Asegura que el efecto de persistencia automática funciona; si no se guarda, el cambio se pierde al recargar. |
